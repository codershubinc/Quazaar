# File Share API

// endpoint /api/v0.1/fileshare/create-accept-uri [GET]
// Description: Creates a temporary, time-limited URI for accepting a file upload. Used to generate a QR code or link.
// Required Headers:
//   Authorization: Bearer <token> (Recommended, though implementation details may vary)
// Response Data (JSON):
// {
//   "acceptUri": "/api/v0.1/fileshare/acceptfile?deviceId=xyz&token=abc",
//   "message": "Temporary file share URI created successfully",
//   "expiry": 3600,
//   "time": "Mon, 02 Jan 2006 15:04:05 GMT"
// }

// endpoint /api/v0.1/fileshare/acceptfile [POST]
// Description: Uploads a file to the server using the temporary credentials generated by `create-accept-uri`.
// Query Params:
//   deviceId: "device_id_string" (from create-accept-uri)
//   token: "temp_token_string" (from create-accept-uri)
// Required Body (Multipart/Form-Data):
//   file: <binary_file_content>
// Response Data:
// Status 200 OK (on success)
